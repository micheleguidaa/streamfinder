# StreamFinder

Pagina web statica (un solo `index.html`, niente build) che per partite, film e serie TV mostra dove vederli gratis o al prezzo più basso, anche su emittenti estere, con i passaggi per VPN e CAP.

**Online:** https://micheleguidaa.github.io/streamfinder/

Per provarla in locale basta aprire `index.html` nel browser.
